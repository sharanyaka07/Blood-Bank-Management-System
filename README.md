# Blood Bank Management System

A web-based application to manage blood donations, stock levels, and urgent blood requests efficiently.

## Technologies

- **Backend**: Flask (Python)  
- **Database**: Supabase (PostgreSQL)  
- **Frontend**: HTML + Jinja2 templates (server-rendered)  
- **Python packages**: Flask, supabase-py, python-dotenv
